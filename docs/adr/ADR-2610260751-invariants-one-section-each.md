# ADR-2610260751: The invariants, one section each

## Context

The review agents cite invariants by id. The Rust specialist checks I4,
I6 and I10, and the performance specialist checks I9. The security
generalist checks I2, I4, I6 and I8. A low-effort agent that sees only
the id may not open the source. So the stakeholder asked for each cited
invariant to be included in the agent's body through mdsmith.

mdsmith includes one value of a file through `extract:`, which walks
the file's projection under a declared schema. The ten invariants were
one list, which projects as a single array, and `extract:` cannot index
an array.

## Decision

Each invariant becomes its own section of `docs/srs/invariants.md`,
headed by its id (`## I1` to `## I10`), its title in bold at the start
of its paragraph. The `invariants` kind in `.mdsmith.yml` declares the
ten sections, so `extract: i2` includes I2's text.

The words of every invariant are unchanged; three things about their
form change. Each list marker goes. Each id leaves the bold lead-in
and becomes the section's heading: `- **I1 — Nothing is lost.** ...`
becomes `## I1`, then `**Nothing is lost.** ...`. The paragraphs
reflow. Three files
include the invariants in full: CLAUDE.md, AGENTS.md and README.md; the
SRS introduction links to them. They show the same text under ten
headings. CLAUDE.md
and AGENTS.md may run to 330 lines to hold them.

## Alternatives

- Embed the whole list in every agent that cites an invariant. That
  costs about 1,500 tokens on every specialist call, and most agents
  cite one or two.
- Keep the ids and link to the source. A low-effort agent may not open
  the link, which is what the stakeholder ruled out.

## Consequences

- ENG-29 holds for this change as for any other to the invariants:
  this record names ENG-29 and lands with it, with the security
  reviewer's approval below.
- An agent's copy of an invariant cannot drift from the source:
  `mdsmith check` fails when an included section differs.
- A later change to an invariant's words changes one section, and
  every agent that includes it is regenerated by `mdsmith fix`.
