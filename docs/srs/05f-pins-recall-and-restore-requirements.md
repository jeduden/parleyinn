## 5.4 Recall (RCL)

| RCL-01 | P0  | ParleyInn's MCP server MUST expose the recall tools `event_search`, `event_expand`, `event_get`, `landmark_list`, `pin_list`, and `stat_list`, and `mcp_server_get`, which is no recall tool: it returns whether the MCP server holds its session binding, whether its search index is readable, the count of its timed-out searches and its version, as closed words and counts and no recalled content, for a call whether or not a run is found for it, and records no recall event.                                                                                                                                                                        | T   | I1     |
| RCL-02 | P0  | `event_search` MUST accept filters for run, time range, provenance class, event kind, and trust level, and return at most `k` hits (default 10, maximum 50) ranked by BM25 with length normalization and per-run damping.                                                                                                                                                                                                                                                                                                                                                                                                                                      | T   | —      |
| RCL-03 | P0  | `event_expand` and `event_get` MUST return exact post-redaction content, resolving payload references, subject to a per-call cap (default 8,000 model tokens†) with a continuation cursor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | T   | I1     |
| RCL-04 | P0  | All recalled content MUST be returned inside the envelope (§9.3). | RCL-05 | P0  | Recall scope MUST default to `run`: the calling agent's current run, through every writer of its seats, which record its delegate reports. A foreign room MUST be reached only under RCL-10, never through the `room` or `rooms` scope. Whether a call may name a room of its principal's that every run seat of the agent has left or lost to a kick or a bar, which neither scope reaches, is open (OQ-45). | T   | I8     |
| RCL-06 | P0  | A quarantined address MUST return a quarantine marker, and a purged range a tombstone (SEC-12).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | T   | I5     |
| RCL-07 | P0  | Every recall MUST be recorded as an event (provenance `assistant` for the query, with the addresses of the returned events).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | T   | I6     |
| RCL-08 | P1  | Every address form ParleyInn shows, and the ASCII input form, MUST be accepted wherever an address is taken, on the CLI and by `event_get` or `event_expand`, resolving to the same events, a tombstone or a quarantine marker. ## 5.5 Landmarks (LMK)

| ID     | Pri | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Ver | Traces |
| ------ | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | ------ |
| LMK-01 | P0  | ParleyInn MUST split each run into spans, starting one at every user turn, every turn whose input a run's tool call supplied (PRV-08), compaction, subagent start or end, each new transcript generation (REC-07), and whenever the run's events move to another seat's writer; a run's last span MUST close at its end, which the MCP server records as a structural event when a subagent's report (`subagent_result`) or the task notification naming it reaches its parent's transcript or the harness session ends. Span boundaries MUST be a deterministic function of the record. | T   | I10    |
| LMK-02 | P0  | ParleyInn MUST produce one landmark per closed span containing only structural fields: address range, turn range, event counts by kind, tool names with call counts, touched file paths, and an error indicator.                                                                                                                                                                                                                                                                                                                                                                         | T   | I2     |
| LMK-03 | P0  | Every structural field untrusted input can influence (file paths, tool names, MCP server names) MUST be sanitized to an allow-listed character set (`A–Z a–z 0–9 . _ / @ : + -`) and a maximum length (default 80†); non-conforming values MUST be replaced with `<field:HASH8>`.                                                                                                                                                                                                                                                                                                        | T   | I2     |
| LMK-04 | P0  | Flagged and quarantined events MUST contribute only to counts, never to text fields.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | T   | I2, I5 |
| LMK-05 | P0  | Landmarks MUST roll up into tiers of at most `k` landmark blocks (`k` ≥ 3, default 8†): a full tier keeps its newest in full detail and collapses the older ones, one line each, into one landmark block of the next tier, bounding the landmark index of a run of n spans to O(k · log_k n) landmark blocks.                                                                                                                                                                                                                                                                            | T   | I10    |
| LMK-06 | P2  | ParleyInn MAY generate natural-language headlines for spans whose every event is trusted, only by a deterministic template over trusted fields.                                                                                                                                                                                                                                                                                                                                                                                                                                          | T   | I2     |

| CMP-09 | P2  | Parallel model sub-calls over record data MAY be supported only through harness mechanisms.
