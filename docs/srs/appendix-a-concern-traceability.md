## B. How poisoning risk scales

| #   | Concern                                                                   | ParleyInn's response                                                                                                                                                                                  | Requirements                   |
| --- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| B1  | Auto-injection multiplies carry-over of poison (64.7% vs 17.4% pull-only) | Pull-only by design                                                                                                                                                                                   | INJ-03, INJ-04, ADR-03         |
| B2  | Poison accumulates; a lossless store never forgets it                     | Quarantine without deletion; retention windows for untrusted payloads; rebuildable derived artifacts                                                                                                  | SEC-12, REC-15, ADM-08         |
| B3  | Store growth doesn't dilute poison; manual review stops being feasible    | Flags set at ingest, visible in recall and queryable; flagged text contributes only counts to landmarks                                                                                               | PRV-07, LMK-04                 |
| B4  | Compaction as a write channel                                             | Compaction summaries untrusted and never restored; structural landmarks only                                                                                                                          | PRV-03, INJ-09, LMK-02, ADR-10 |
| B5  | Shared memory multiplies blast radius                                     | Recall defaults to the agent's current run, extends only to rooms it has a seat in and the cross-room posts they show, and reaches a foreign room only when the call names it; no shared stores in v1 | RCL-05, NG4, MEM-01            |
| B6  | Unattended agents act on poisoned content with nobody watching            | Audit log; recall taint, with an example `PreToolUse` hook handler that asks for approval once a run carries it                                                                                       | OPS-01, OPS-02, SEC-13         |
| B7  | Per-prompt search cost and stalls grow with the store                     | No per-prompt search by default; latency targets at 1M–10M events; bounded queries                                                                                                                    | INJ-04, NFR-01, NFR-03, SEC-04 |
| B8  | Structural fields (file names, MCP tool names) as an injection vector     | Allow-list sanitization                                                                                                                                                                               | LMK-03                         |
| B9  | Repository configuration could downgrade security                         | A repository's `.parinn.toml` can only tighten the principal's configuration                                                                                                                          | SEC-11                         |
| B10 | Prompts on runners may carry external content (e.g. issue text)           | `automation` deployment mode by default treats `user` events as untrusted                                                                                                                             | PRV-04                         |
